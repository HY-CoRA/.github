# HY-CoRA

한양대학교 중앙 코딩 동아리 **HY-CoRA**입니다.
전공과 상관없이 코딩으로 무언가를 만들어 보고 싶은 사람들이 모여, 함께 배우고 함께 만듭니다.

## 하는 일

- **스터디** — 프로그래밍 기초부터 웹·앱·AI까지, 학기마다 주제를 정해 함께 공부합니다.
- **프로젝트** — 팀을 꾸려 실제로 돌아가는 서비스와 게임을 만들고 배포합니다.
- **대외 활동** — 과학 축제·부스 운영 등 코딩을 바깥에 소개하는 자리에 참여합니다.
